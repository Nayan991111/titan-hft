# The manuscript

`main.tex` is the IEEEtran source. `refs.bib` holds only citations verified
against at least two independent bibliographic sources or read directly.

## Build

    cd docs/paper
    pdflatex main && bibtex main && pdflatex main && pdflatex main

IEEEtran V1.8b (2015/08/26) and IEEEtran.bst are required. On Debian or Ubuntu
they come from `texlive-publishers`.

## Dashes: the one place this project's rule yields, and why

This project excludes em dashes and en dashes from everything written for it.
The LaTeX source obeys that completely: it contains zero em dash and zero en
dash characters, and zero `-` `-` or `-` `-` `-` ligature sequences, including
in the bibliography, where page ranges use a single hyphen rather than the
conventional double hyphen.

The compiled PDF nonetheless contains six, and every one is generated by
IEEE's own files rather than by the prose:

| Source | Count | What it is |
|---|---|---|
| `IEEEtran.cls` | 2 em | the dash after `Abstract` and after `Index Terms` |
| `IEEEtran.bst` | 2 em | the repeated-author dash in a reference whose authors match the one above it |
| `IEEEtran.bst` | 2 en | page ranges, which the style file normalises from single hyphens |

These are IEEE house typography. Removing them means editing `IEEEtran.cls`
and `IEEEtran.bst`, which would make the manuscript non-conformant to the
format it claims to use, and a reviewer or an automated format check would be
right to flag that. So they stay, and the distinction that matters is recorded
here: **no dash in this paper was written by its author.**

`scripts/check_dashes.py` enforces exactly that distinction. It fails on any
dash in the source and ignores the six the IEEE files generate in the output.

## arXiv packaging

arXiv runs neither `bibtex` nor `biber` on an uploaded `.bib` file, so the
tarball must carry a prebuilt `main.bbl`. It must also carry `IEEEtran.cls`,
because arXiv's TeX installation cannot be assumed to hold it. `\pdfoutput=1`
is already on line 1 of `main.tex`, inside the first five lines, which is where
arXiv looks for it.
